类的初始化顺序

在有虚继承的情况下，类的初始化顺序（构造顺序）：
1.虚基类（虚基类就是最深层的公共基类）最先构造
2.按继承声明顺序构造普通基类
3.构造派生类自己的成员

也就是说，中间类（Printer 和 Scanner）对 Device 的构造调用会被忽略，只有 AllInOne 的调用生效。

向上转型（upcast）与object slicing（对象切片）

向上转型：将派生类的 指针 或 引用，隐式转换为基类的指针或引用。这是安全的，因为派生类包含基类的所有成员。

什么是对象切片：当你用派生类对象去 初始化或赋值给一个基类对象 时，派生类独有的成员会被“切掉”，只剩下基类部分。
不过切片只发生在值传递/赋值中，引用和指针不会触发切片。

upcast is a kind of standard conversion

总之，标准转换时C++中编译器可以自动完成的类型转换，有这些:

  • 调整或变换
    • array-to-pointer conversion: void f(int *); int a[10]; f(a);
    • qualification conversion: void f(const int *); int *p; f(p);
  • Promotion
    • integral promotion: void f(int); char c; f(c);
    • floating-point promotion: void f(double); float x; f(x);
  • Numeric conversions
    • integral conversion: void f(int); long long l; f(l);
    • floating-point conversion: void f(float); double x; f(x);
    • floating-integral conversion: void f(int); double x; f(x);
    • pointer conversion: T * p = nullptr; void * p2 = p;
      • Upcast: Base * pb = &derived;
    • boolean conversion: bool b1 = i, b2 = p, b3 = x;

virtual关键字

纯虚函数与抽象类

如果一个类包含（或继承）了纯虚函数，且 最终重写者（final overrider）仍是纯虚函数，那这个类就是 抽象类 。

virtual实际上是为了多态服务的，virtual 告诉编译器：这个函数在派生类中可能被重写，调用时请根据对象的 实际类型 决定调用哪个版本。（不写的话只能调用基类的函数，在上面这个基类里甚至无法实现，因为...=0;这是一个 纯虚函数，使得这个基类是一个 抽象类，使得Shape s;创建抽象类对象的行为无法实现！）
抽象类不能创建对象，但可以拥有指针或引用（这是多态的基础）。

所以在这里do_draw()是一个 virtual function(虚函数)。Virtual functions 的行为可以被派生类 override（重写 / 覆盖）

virtual 改变了行为：编译器不再在编译时决定调用哪个函数，而是在运行时查找对象的实际类型，然后调用对应的函数。这种机制叫做 动态绑定 或 运行时多态。

声明或继承了 virtual function 的类称为 polymorphic class(多态类)。

override

override 是 C++11 引入的一个“意图声明”，它的作用是在编译时检查“这个函数是否真的在重写一个基类的虚函数”。如果基类没有这个虚函数，或者签名不匹配,会编译报错。

override是可以不写的。编译器不帮你检查了，这在某些情况下（比如draw()和draw(int)，在编译器检查重写时这算两个不同的函数，因为函数签名不同）可能会在运行时发现多态行为不符合预期，却很难定位问题。

Virtual Call（虚函数调用）

对虚函数的调用称为 virtual call 或者 virtual function call，它会使用调用对象的实际类型中的 the final overrider

final:终止重写链

  • 加在类上：这个类不能再被继承。
  • 加在虚函数上：这个函数在派生类中不能再被重写。

小结

派生类可以重新定义 (类似但不是 override) 非 virtual 成员函数，但通常不要这么做。(如果你通过基类指针调用这个函数，调用的是基类版本，而不是派生类版本，会造成行为不一致)

做这样的事情的场景一般是，子类有更多的信息，从而能以更高的效率完成 相同 的工作；但程序员应当保证子类和基类的这一函数的行为是相同的。

虚函数实现（virtual table————vtable）

C++的多态是如何实现的？（在类这里，前面STL、模板是另一块），答案是通过基类指针或引用调用虚函数时，自动找到派生类的版本。这是一种 动态绑定。

vtable 就是用来支持这个“运行时查找”的数据结构。vtable 是一个函数指针数组，存储了类中所有虚函数的实际地址。

virtual call

虚函数调用有一些额外开销的，既然我们已经知道它的实现的原理了：

  • 间接跳转:通过 vtable 取地址再跳转，比直接调用多一次内存访问和一次跳转
  • 无法内联:编译器通常无法在编译期确定调用目标，因此无法内联展开函数体
  • vptr 存储:每个对象多占用一个指针大小的内存（64 位系统为 8 字节）

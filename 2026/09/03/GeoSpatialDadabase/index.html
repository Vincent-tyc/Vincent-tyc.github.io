1. Geospatial Database

研究一下这门课的学习要点

1.1. SQL

SQL(structured query language),也就是结构化查询语言。但是SQL的功能不只是查询。

1.1.1. SQL拆解

SQL分为以下几个部分：

  • DDL(data-definition language，数据定义语言)：提供定义关系模式、删除关系和修改关系模式的命令
  • DML（data-manipulation language，数据操纵语言）：提供了从数据库获取信息、以及对数据库内的元组增删改等能力
  • 完整性：DDL 提供了指定完整性约束的命令
  • 视图定义：DDL 提供定义视图的命令
  • 事务控制：指定事务起始点和终点的命令
  • 嵌入式 SQL 和动态 SQL：定义如何将 SQL 语句嵌入于通用目的的编程语言中
  • 授权：指定访问关系和视图的权限的命令

1.4. 关系代数（Relationship Algebra）

关系代数是一组 以集合（表）为操作对象、以关系（表）为结果 的运算规则。它定义了如何从一个或多个表（关系）中派生出新的表（关系）。

六大关系：

  • 选择（Select）:WHERE从表中选出满足条件的行σ (sigma)
  • 投影（Project）:SELECT 列名从表中选出指定的列π (pi)
  • 并（Union）:UNION两个表的行去重∪
  • 交集∩
  • 差（Set Difference）:EXCEPT/NOT IN在A表但是不在B表中的行−
  • 笛卡儿积（Cartesian Product）:CROSS JION两个表的行两两组合×
  • 更名（Rename）:AS给表或列起别名ρ (rho)
  • 连接（bowtie）:JION...ON/NATURAL JION将两张表拼接起来⨝

1.6. 一个实际例子(应该叫关系型数据库标准语言)

SELECT

  • SQL 语句不允许名称中出现 - 字符，请用 _ 替代
  • 并且 SQL 对关键字 大小写不敏感 (case insensitive)，也就是说 SQL 将同一字符的大小写形式看作是同一个字符
  • SQL 允许关系和查询结果中出现重复记录 (duplicates)（默认使用 ALL 关键字，因为消除重复记录太耗费时间了）。要想强制消除重复记录，可以在 SELECT 后使用 DISTINCT 关键字，即 SELECT DISTINCT …
  • 使用 * 表示选择所有属性，比如 SELECT * FROM r 表示选择 r 中的所有属性
  • SQL 允许查询语句中对常量或属性使用简单的算术表达式，包括加减乘除，对应关系代数的广义投影(generalized projection)
    • 比如 SELECT ID, name, salary * 1.05 FROM instructor;

WHERE

WHERE语句对应关系代数中是那个 选择谓词（selection predicate）

  • 在 WHERE 从句的比较表达式内，可以使用逻辑连接词 AND、OR、NOT 以及 BETWEEN
    • 其中 BETWEEN 用于指定一个值的闭区间范围，也就是说 WHERE x BETWEEN a AND b 就是 a <= x <= b。
    • 对应地有 NOT BETWEEN（但是开区间）：WHERE x NOT BETWEEN a AND b 对应 x < a 或 x > b
  • 在比较表达式中，可以使用行构造器(row constructor)，同时进行多个属性（位于同一个元组中）的比较，比较顺序按词典序(lexicographically) 排序。

FROM

  • FROM 从句列出包含在查询语句内的关系，对应于关系代数的笛卡尔积(Cartesian product)（如果指定多个关系的话）

SQL支持关系代数中的集合运算符，∪, ∩, ˉ，分别用 UNION、INTERSECT、EXCEPT 表示

注意使用这些运算符后会自动消除重复记录。（因为集合不允许存在重复记录）如果想保留重复记录需要在关键字后面加上ALL关键字。即UNION ALL INTERSECT ALL EXCEPT ALL

1.6.8. NULL 空值

这里有些复杂，以后再来探索吧！

SQL的逻辑表达式结果有3种：true、unknown、false

使用谓词 IS NULL 和 IS NOT NULL 来检查是空值或不是空值

NULL 表示”不知道”或”不存在”，它不是：

  • 不是 0
  • 不是空字符串 ‘’
  • 不是 false
  • 就是”不知道” NULL 的运算，结果都是 NULL（不知道）。

不能使用 … = NULL 比较，因为这样的比较结果恒为 null，没有任何意义。

对 UNKNOWN 的处理：它只作用于逻辑判断。在 WHERE、HAVING、CASE WHEN 等子句中，只有结果为 TRUE 的行会被选中，结果为 FALSE 或 UNKNOWN 的行都会被过滤掉。

1.7. SQL语法执行顺序

插播一个表格快捷键alt + shift + f，快速建起一个表格~

执行顺序 子句 作用 别称/关键词
1 FROM 确定数据来源：读取哪张表（以及JOIN连接） 数据源
2 ON JOIN的匹配条件（对笛卡尔积进行筛选） JOIN条件
3 JOIN 如果有多张表，进行连接操作，生成中间结果集 表连接
4 WHERE 对行进行筛选（分组前过滤） 行过滤
5 GROUP BY 对筛选后的数据进行分组 分组
6 HAVING 对分组后的结果进行筛选（分组后过滤） 组过滤
7 SELECT 选择要输出的列，计算聚合函数和表达式 列投影
8 DISTINCT 对结果集进行去重 去重
9 ORDER BY 对最终结果进行排序 排序
10 LIMIT / OFFSET 限制输出的行数 分页
